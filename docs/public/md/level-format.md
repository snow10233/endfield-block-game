# 關卡文字格式 (Level Format)

關卡資料採用純文字儲存，方便玩家分享與手動修改。解析邏輯實作於後端的 `FileLoader`。

## 格式定義

檔案依序包含以下區塊：
1. **基礎設定**: `[顏色數量] [列數(Rows)] [行數(Cols)]`
2. **顏色目標 (每個顏色重複一次)**:
   * 該顏色在各列的目標數量 (`rowNeed`)
   * 該顏色在各行的目標數量 (`colNeed`)
   * 固定色塊數量 `fixedCount`
   * 固定色塊座標清單 `[row] [col]`
3. **不可放置的禁區 (Blocked Cells)**:
   * 禁區數量 `nonColorFixedsNum`
   * 禁區座標清單 `[row] [col]`
4. **零件清單 (直到檔案結束)**:
   * `[Color ID] [Rows] [Cols]`
   * 接下來的 `Rows` 行輸入二維陣列 (0代表空，1代表實體)

## 範例：3x3 基礎關卡

```text
1 3 3        // 1種顏色, 3x3棋盤
3 2 1        // 列目標: 3, 2, 1
3 2 1        // 行目標: 3, 2, 1
0            // 0個固定格
0            // 0個禁區
0 2 2        // 零件1: Color 0, 2x2
1 1
1 0
0 1 3        // 零件2: Color 0, 1x3
1 1 1
```
