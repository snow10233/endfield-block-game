# 關卡設計器 (Level Designer)

內建的關卡設計器允許玩家在 GUI 中自訂棋盤、目標數字與多種零件，並匯出成 `.txt` 關卡檔。

## 核心防呆機制 (Validation)

為了確保玩家不會創造出「不可能通關」的無解關卡，設計器引入了嚴格的即時驗證機制：

1. **狀態收集**：每當玩家修改棋盤大小、塗改禁區、調整目標數字或增刪零件時，Vue 會將當前的 UI 狀態打包。
2. **背景驗證**：前端會透過 IPC 發送 `validateLevelString` 指令。
3. **Solver 試算**：C++ 後端會解析這段字串，並在記憶體中啟動 Solver 嘗試找出至少一組解。
4. **輸出鎖定**：只有當 Solver 回傳 `ok: true` (有解) 時，右上角的「存檔」與「輸出文字」按鈕才會解鎖。若為無解，系統會強制顯示紅字警告，防止產出無效的關卡檔。
